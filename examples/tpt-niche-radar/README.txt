NICHE RADAR — TPT OPPORTUNITY STUDIO v3.0

Open START-HERE.html for installation, screenshots, and a feature guide.

QUICK INSTALL
1. Extract this folder.
2. Chrome > chrome://extensions > Developer mode > Load unpacked.
3. Select this TPT Extension folder (the one with manifest.json).
4. Open Niche Radar from the toolbar > Open research workspace.
5. Load the two included CSVs, or drag your CSV archive into the dashboard.

UPDATING THE OLD EXTENSION
Replace files in its existing folder, keeping the same path, and click Reload
in chrome://extensions. Old scrapedData is migrated if it is still available.

No npm install, build command, API key, remote script, or subscription is needed.
All code, assets, and samples are included. Data is stored in your browser.
Back up your workspace as JSON before uninstalling or moving folders.
